# 🎓 BCA-Walla — Smart Learning Platform for BCA Students

🚀 A full-stack EdTech platform designed specifically for BCA students to **access notes, participate in coding contests, track progress, and compete on leaderboards** — all in one place.

---

## 📌 Features

* 📚 **Study Notes Access**
  Organized and easy-to-access notes for various BCA subjects.

* 🧠 **Online Coding Contests**
  Participate in contests and improve problem-solving skills.

* 📊 **Progress Tracking**
  Track performance over time with structured analytics.

* 🏆 **Leaderboard System**
  Compete with peers and stay motivated through rankings.

* 🚀 **Skill Development**
  Explore new concepts and improve technical skills.

---

## ⚡ Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://https://github.com/ajay5689pal/onlinewala.git
cd onlinewala
```

### 2️⃣ Create virtual environment

```bash
python -m venv venv
source venv/bin/activate   # (Windows: venv\Scripts\activate)
```

### 3️⃣ Install dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Setup database

* Configure your SQL database
* Update database credentials in config file

### 5️⃣ Run the application

```bash
python app.py
```
